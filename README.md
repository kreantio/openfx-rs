# OpenFX bindings and tools for Rust

## Prerequisites

To build the crate `openfx`, you will need to install the following tools:

- [`just`]

To build some of the examples, you will need to install the following tools:

- [`just`]
- [`deno`]

[`just`]: https://github.com/casey/just
[`deno`]: https://deno.com/

## crate [`openfx`](./crates/openfx/)

Bindings for the OpenFX API in different abstraction layers.
