## Prerequisites

The following tools are required:

| Tool(s) \\ To                           | Use crate `openfx` | Build Examples | Update Generated Code in Crate `openfx` |
| --------------------------------------- | ------------------ | -------------- | --------------------------------------- |
| The [Rust] programming language         | stable             | nightly[^1]    | stable                                  |
| POSIX tools (`sh`, `rm`, `mkdir`, etc.) | no                 | yes            | not strictly                            |
| [`just`]                                | no                 | not strictly   | not strictly                            |

[Rust]: https://rust-lang.org/
[`just`]: https://github.com/casey/just

[^1]: Only because
    [`cargo build --artifact-dir` is unstable](https://github.com/rust-lang/cargo/issues/6790).

## Internal Crates

| Name                       | Published? | Description                                           |
| -------------------------- | ---------- | ----------------------------------------------------- |
| [`openfx-internal-macros`] | Yes        | internal procedural macros for the crate `openfx`     |
| [`openfx-codegen`]         | No         | a CLI tool for generating code for the crate `openfx` |

[`openfx-internal-macros`]: crates/openfx-internal-macros
[`openfx-codegen`]: crates/private/openfx-codegen

## Subprojects

- openfx-datagen: https://github.com/kreantio/openfx-datagen
  - a tool for generating data from the official OpenFX C headers
- openfx-data: https://github.com/kreantio/openfx-data
  - stores data generated by openfx-datagen
